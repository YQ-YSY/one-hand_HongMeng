打字方法
------
（1）鸿蒙手机、鸿蒙电脑=>打开某个软件，点击文本框=>这时会弹出“单手笔顺“的数字键盘。<br>
（2）按数字键1234567890=>在候选框可以看到有汉字显示=>选择您所需的字词，或按空格键，或按标点符号键=>汉字就能打上去。<br>
（3）按数字键1234567890=>按“换行”键=>直接把数字打上去（忽略汉字）。<br>
（4）打词组时，使用小数点 . 分隔每个汉字的数字编码，例如：34.123.4125（人才市场）<br>
（5）每2个数字搭配，可打出偏旁部首（部件、字根），提高打字速度。<br>
（6）每个汉字最少一个编码，最多6个编码，词组重码率极低，只要排在候选框的第一位，就可以按空格键打上去，后续编码可以省略。<br>
（7）如果忘记了某个字怎么写，想切换回拼音输入=>键盘左下角，长按“地球”图标=>可以选择“中文26键”（小艺输入法）。<br>

学习方法
------
（1）请解压缩“单手笔顺（鸿蒙）.zip”文件=>打开里面的“教程”文件夹。<br>
（2）请查看《单手笔顺输入法（偏旁部首）代码表》。<br>
（3）请阅读《单手笔顺输入法（3.0版）使用指南》PDF图文教程。<br>
（4）请打开《单手笔顺输入法（Rime版）打字技巧教程、安装方法教程》网页文件，查看里面的视频教程（网址）。<br>
（5）请用WPS打开《单手笔顺输入法——初学者练习手册》TXT文本文件，按里面的步骤，对照《代码表》进行打字练习。<br>
（6）简单的偏旁部首12345开头，复杂的偏旁部首78960开头，《代码表》很有规律，很容易记，上手就能盲打。<br>
（7）不允许“跨越笔顺”拆字，例如：“国”字不能拆成“口+玉”，必须是国标笔顺的“冂+王+丶+一”。<br>
（8）容易出错字请参阅《单手笔顺输入法（3.0版）使用指南》PDF图文教程最后一页。例如：“万”字的国标笔顺是“一+⺄+丿”，“里”字的国标笔顺是“日+丨+二”。<br>

<h2>鸿蒙“超越输入法”使用技巧</h2>
（1）输入框左上角：点击“b”图标=>设置=>打开全部选项。<br>
（2）键盘的"后退删除"按键，可以“上滑”清空之前的输入，或者“下滑”重做。<br>
（3）键盘的按键，除了“上滑、下滑”之外，还可以“长按”，在弹出的菜单中选择所需的字符。<br>
（4）按下“字母、符号、更多、中/英”等按键，可以切换到字母键盘、标点符号键盘。<br>
（5）按下“顺”字按键，可以切换回“单手笔顺“的数字键盘。<br>
（6）启动“超越输入法”=>主题=>选择“中文输入26键(带数字)”=>也可以用数字键打出汉字。“九宫格、中文9键”的数字打不出汉字，切换到“123”数字键盘才能打出汉字。<br>
（7）如果“超越输入法”导入的次数太多、太乱，可以点击“还原”按钮，全部清除，再重新导入。<br>
